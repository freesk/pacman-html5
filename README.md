# Pacman HTML5

A small Pac-Man-style chase game drawn on an HTML5 canvas and animated with [GSAP](https://greensock.com/gsap) (TweenMax). Move the yellow ball through the maze with the arrow keys while the blue ball chases you along the shortest path. The game ends when it catches you.

![Pacman HTML5 demo](http://i.imgur.com/nHkiNMk.gif)

## Usage

Open `index.html` in a browser. No build step is needed.

The `clickable-version` branch has an earlier variant where you click a cell and the ball walks to it along the shortest path.
